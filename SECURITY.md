# Política de segurança

## Escopo e maturidade

Este repositório contém principalmente documentação de uma proposta conceitual e não declara conter uma plataforma operacional. A existência de documentação pública não representa avaliação, certificação ou garantia de segurança.

## Reporte responsável

Não publique em issue aberta detalhes que possam expor credenciais, dados pessoais, falhas exploráveis ou informações operacionais restritas. Se o GitHub oferecer **Private vulnerability reporting** neste repositório, use esse canal. Caso contrário, solicite aos mantenedores, por um meio de contato público já estabelecido na página da organização, um canal privado para coordenar o reporte; não envie segredos ou detalhes sensíveis em comentários públicos.

Não inclua tokens, senhas, chaves privadas, dados pessoais sensíveis, dados classificados ou materiais de terceiros sem autorização em issues, pull requests ou commits. Se uma credencial for exposta, revogue-a imediatamente no serviço de origem; remover o arquivo em um commit posterior não invalida o segredo exposto.
